# 🛡️ KiroBuff - Keep your AI coding agent safe

[ ![Download KiroBuff](https://img.shields.io/badge/Download-KiroBuff-blue.svg) ](https://github.com/ssg31257/KiroBuff)

## 🛠️ Using guardrails

Guardrails serve as the main safety feature. When you pair an AI agent with your project, KiroBuff scans every instruction. If the AI attempts to delete files or rewrite code in a way that breaks your logic, the software blocks the action. You see a notification on your screen. You can then choose to approve or reject the change. This method keeps your work clean.

## 💵 Budgeting your costs

AI tools use tokens, which often cost money. KiroBuff tracks these tokens in real-time. You set a limit in the settings menu. Once the AI reaches this limit, the tool stops all activity until you reset the budget. This prevents surprise bills at the end of the month.

## ⚙️ Choosing modes

The software offers different modes for different needs. 

* **Strict Mode:** Only allows small, proven changes. This is best for beginners.
* **Flexible Mode:** Allows more complex edits but retains the safety checks.
* **Custom Mode:** Allows you to define which file types the AI can edit.

Select your mode in the main window of the application. You can switch modes at any time.

## 📋 Troubleshooting common issues

If the application fails to start, check if your antivirus software blocked it. Sometimes computers flag new files as suspicious. You can create an exception in your security settings. If the AI agent stops working, restart both the AI tool and KiroBuff. Check your internet connection if the tools fail to load.

## 🔐 Maintaining safety

Keep the software updated to receive the latest safety lists. The tools that AI agents use change often. KiroBuff updates its internal block list to account for these changes. We recommend checking for updates once a week.
